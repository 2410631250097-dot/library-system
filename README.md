# Library System

## Description
Simple Library Information System

## Requirements
- PHP
- Composer
- MySQL
- Laravel

## Installation
1. Clone the repository.
2. Run composer install.
3. Configure the .env file.
4. Create a MySQL database named library_system.
5. Run php artisan migrate.
6. Run php artisan serve.
